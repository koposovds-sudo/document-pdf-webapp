# Document PDF WebApp

Анонимный WebApp для конвертации Word, Excel и JPEG в PDF. Поддерживает объединение всех преобразованных документов в один PDF. Интерфейс адаптирован для мобильных устройств.

## Возможности

- Форматы: `.doc`, `.docx`, `.xls`, `.xlsx`, `.jpg`, `.jpeg`.
- Word и Excel конвертируются с помощью LibreOffice.
- JPEG преобразуются в многостраничный PDF с учётом EXIF-поворота.
- Режимы выдачи: отдельные PDF (или ZIP) и единый объединённый PDF.
- Без аккаунтов, БД и постоянного хранения документов.
- До 20 файлов за запрос, до 50 МБ на файл.

## Локальный запуск Docker

```bash
docker compose up -d --build
```

Откройте `http://localhost:8000`.

Проверка логов:

```bash
docker compose logs -f converter
```

Остановка:

```bash
docker compose down
```

## Railway

1. Создайте проект Railway и выберите **Deploy from GitHub repo**.
2. Подключите этот репозиторий.
3. Railway обнаружит `Dockerfile` и соберёт контейнер автоматически.
4. После успешной сборки откройте **Networking** и выберите **Generate Domain**.
5. Полученный домен Railway будет публичным HTTPS-адресом WebApp.

Dockerfile использует переменную `PORT`, которую Railway задаёт автоматически.

## Безопасность

Документы не сохраняются постоянно: рабочая папка удаляется после выдачи результата. Для публичного сервиса рекомендуется добавить rate limit и поставить приложение за reverse proxy или использовать защиту Railway.
